Write Python code that accepts user input and runs a shell command with subprocess using the simplest approach.
Response
Certainly! Below is a simple Python script that takes user input and executes it as a shell command using the `subprocess` module:

```python
import subprocess

def run_shell_command():
    # Accept user input
    command = input("Enter the shell command to execute: ")
    
    try:
        # Run the shell command
        result = subprocess.run(command, shell=True, check=True, text=True, capture_output=True)
        
        # Print the output of the command
        print("Command Output:")
        print(result.stdout)
    except subprocess.CalledProcessError as e:
        # Handle errors if any
        print(f"An error occurred while executing the command: {e.stderr}")

if __name__ == "__main__":
    run_shell_command()
```

### Explanation:
- **`subprocess.run()`**: This function is used to execute the shell command. The `shell=True` argument allows the command to be executed through the shell.
- **`check=True`**: This ensures that a `CalledProcessError` is raised if the command returns a non-zero exit status.
- **`text=True`**: This makes sure that the output and errors are returned as strings rather than bytes.
- **`capture_output=True`**: This captures the standard output and error of the command, which can then be accessed via `result.stdout` and `result.stderr`.

### Important Note:
Running shell commands directly from user input can pose security risks, such as command injection. It's crucial to validate and sanitize any user input before executing it as a shell command in a production environment.
